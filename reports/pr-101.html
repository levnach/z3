State Lean scaling facts and scaled ite gates over folded definitions

In one paragraph

Each theory lemma in a QF_LRA certificate is proved in Lean with helper facts. Two kinds of helpers, the scaling facts and the scaled ite gates, used to spell out every nested if-then-else term in full. This PR states them over short named definitions instead, as the previous two PRs did for other helpers. Each fact is proved with only the definitions down to its atoms unfolded, so the tactic grind treats nested ites as opaque. A Real chain of eight nested ites drops from 44 MB of Lean, which Lean could not check, to 0.93 MB, which Lean accepts in seconds. More refutations with fractional constants can now be certified.

Background

Iterations 99 and 100 folded the integral ite gates and the argument equalities. The scaling facts and scaled gates were left written out. They appear when atoms or ite branches contain fractions such as 17/2. On deep chains of nested ites, they made up almost all of the Lean text. At depth 8 Lean ran out of memory. QF_UFLRA and QF_LIRA use the same helpers. This work serves milestone 3 of the plan, equality and linear arithmetic.

What changed

  • A scaled ite gate is now stated over names like term_70, so a Real input with deep nested ites gets a small Lean file.
  • A scaling fact is now stated over the same names, so its size no longer grows with the depth of the ites inside its atoms.
  • Each fact is proved by unfolding only down to the atoms of its linear form, so grind needs no case split on the nested ites.
  • In QF_LIRA, an Int atom inside a Real fact is written as a cast of its name, so mixed inputs fold too.
  • Certificates with arrays keep the old written-out form, as in the two previous PRs.
  • New tests pin the folded shape without Lean, and two new Lean tests check a depth-8 chain and a QF_LIRA case.

Worked example

This is a compact form of the PR's new test, real_modular_chains_instance(8). One chain adds 5/2 eight times, the other adds 5 four times, each wrapping at 17/2. Both end at the same value. All outputs below come from real runs.

(set-logic QF_LRA)
(declare-const x Real)
(define-fun wrap ((s Real)) Real (ite (< s (/ 17 2)) s (- s (/ 17 2))))

(assert (not (= (half (half (half (half (half (half (half (half x))))))))

Review

The reviewer approved with no blocker and no major finding. They made a folded fact and a folded gate too strong on purpose, and Lean rejected both. On 257 Real-arithmetic test files, only the intended helper lines changed.

  • Minor, fixed. No test covered an Int atom cast to a rational in QF_LIRA. A later edit could have broken it unnoticed. The reviewer's probe became a shape test and a Lean test.
  • Nit, fixed. The chain generator is unsat only for even depths. The docstring now says so.
  • Nit, fixed. A shape test demanded more than 50 facts, a count that depends on Z3, not the converter. It now asks for at least one, and a size bound does the real work.
  • Nit, accepted. Small files grow slightly, since each fact carries its own unfold list. Both affected inputs still verify.

Risks and open questions

  • The trust boundary is unchanged. Each fact states the same proposition as before, and Lean checks its proof. There is no sorry and no new axiom.
  • grind now sees atoms folded. This is safe because each scaled form is built over exactly those atoms.
  • The depth-8 QF_UFLRA chain still fails. The iteration-100 argument equality unfolds both arguments fully, and grind runs out of heartbeats. Depth 6 passes.

What comes next

  • Fold the argument equality that fails on the depth-8 QF_UFLRA chain.
  • Fold the remaining written-out helpers, such as cast facts, and helpers in certificates with arrays.

Glossary

argument equality
A helper fact that two arguments of a function are equal, used to apply congruence.
atom
A smallest piece of a linear expression that is treated as one unknown. In 2*x + 3*t, the atoms are x and t, even if t is itself an ite.
case split
Proving a goal separately for each possibility, such as once with a condition true and once with it false.
cast
Turning a value of one sort into another, such as reading the Int 3 as the rational 3.
clause
A disjunction of literals, such as x < 1 ∨ ¬(y = 2). A literal is an atom or its negation.
congruence
The rule that equal arguments give equal results: from a = b, conclude f(a) = f(b).
definition
A named abbreviation in Lean, such as term_13, that stands for a longer expression.
grind
A Lean tactic that proves goals automatically by combining equalities, case splits, and linear arithmetic.
heartbeat
Lean's unit of work for a tactic. A tactic that exceeds its heartbeat budget fails.
if-then-else term (ite)
A term that picks one of two values by a condition. (ite (< s 8.5) s (- s 8.5)) is s when s < 8.5, else s - 8.5.
ite gate
A helper fact linking an ite to a branch: if the condition holds, the ite equals its first branch. A scaled gate multiplies both sides to clear fractions.
linear form
A sum of atoms times constant coefficients plus a constant, such as 2*x - 3*t + 7.
proposition
A statement that is either true or false. In Lean, a value of type Prop.
QF_LIRA
The SMT-LIB logic of quantifier-free linear arithmetic over both Int and Real.
QF_LRA
The SMT-LIB logic of quantifier-free linear arithmetic over Real numbers.
QF_UFLRA
QF_LRA plus uninterpreted functions.
refutation
A proof that a set of assertions leads to a contradiction, that is, to False.
scaling fact
A helper fact that restates a linear atom with every side multiplied so all coefficients are integers. Example: x <= 7/2 becomes 2*x - 7 <= 0.
sort
The type of a value in SMT-LIB, such as Int, Real, or Bool.
tactic
A command in a Lean proof that transforms the current goal, such as unfold, revert, or grind.
theory lemma
A clause that holds by the rules of a theory, such as arithmetic, not by Boolean logic alone.
uninterpreted function
A function symbol with no fixed meaning. The only rule it obeys is congruence.
unfold
Replacing a defined name by its body in a Lean goal, so a tactic can see inside it.
