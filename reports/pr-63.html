In one paragraph

This PR lets the pipeline certify inputs that use to_int and is_int. These are the two conversions out of Real in the qf_lira fragment. In Lean, to_int t becomes the floor Rat.floor t. is_int t becomes SMT-LIB's own definition, "the floor of t equals t". Every theory lemma that touches a floor now gets two bounds on it, taken from lemmas in Lean's core library. Lean's kernel checks these instances, so no new axiom and no sorry appear. The change works on both proof cores. It turns a hard rejection into a checked refutation for a whole family of inputs with a single floor.

Background

PR #62 taught qf_lira to relate Int and Real atoms through to_real. The opposite direction was still missing. The exporter stopped with "unsupported arithmetic operator: to_int" or "unsupported propositional operator: is_int". So even n = (to_int x) had no certificate on either proof core. One real example is the z3test regression issue-1608.smt2. This work serves milestone 3 of the plan, "Equality and linear arithmetic". That milestone asks to finish each arithmetic fragment end to end before adding another.

What changed

  • Exporter. You can now export a qf_lira certificate for an input that applies to_int or is_int to a linear term of sort Real, on both cores.
  • Exporter. Next to an uninterpreted function, these conversions are still rejected.
  • Reconstructor. A theory lemma that reaches a floor now proves itself from two library facts: the floor is at most its argument, and less than it plus one.
  • Reconstructor. When two floored terms differ by an integer, the proof now states that their floors differ by that integer, so Z3's rewrite of is_int (x + 1) to is_int x checks.
  • Tests and docs. Nine documented inputs and four random seeds are now checked by Lean on both cores, and the README and plan describe the encoding.

An analogy for the shift fact: if you raise a whole staircase by exactly one step, every step number goes up by one. The floor of x + 1 is the floor of x, plus one.

Review

The reviewer approved, with no blocker and no major finding.

Minor: the floor of an integer was not stated. The reviewer tried (not (is_int (to_real n))) with n an Int. Both cores accepted it, but Lean then failed to prove it. The two floor bounds alone leave room for the floor of n to be n - 1. This was not unsound, but an accepted input should not fail later. The fix adds the fact "the floor of an integer is itself", through Rat.floor_intCast. Two new test inputs failed without the fix and pass with it.

Nit: the README had the sides reversed. It wrote t = floor t where the generated Lean says floor t = t. It now matches.

Nit: the 12-floor cap was untested. A new test now reaches the cap. Its Lean cost just below the cap stays unmeasured.

Risks and open questions

  • Integrality cuts through a floor of a Real variable are unsupported. The clause log rejects them. The legacy core emits them as Farkas lemma steps that Lean fails to prove.
  • All-Int steps over floors are proved by grind, not omega. Cost on larger inputs is unknown.
  • Integrality facts add one extra cast fact each, also on to_real steps from PR #62.
  • The exporter and reconstructor check cut shapes differently. Both reject explicitly.
  • GitHub CI results on master are unknown to this report.

What comes next

  • Support integrality cuts through floors with branch-and-bound facts.
  • Reject those cuts explicitly on the legacy core too, so both cores agree.
  • Align the two cut shape checks, and measure the cost near the 12-floor cap.

Glossary

atom
The smallest true-or-false piece of a formula, such as x > 2.5. A literal is an atom or its negation.
axiom
A statement accepted without proof. Adding one to Lean would mean trusting it blindly.
branch and bound
Splitting a problem on a value, for example "n ≤ 2 or n ≥ 3", to handle integer constraints.
cut
A derived constraint that uses integrality to tighten a bound, for example from 2n < 3 to n ≤ 1.
exporter
The step that turns Z3's proof into a certificate file for the reconstructor.
Farkas lemma
A proof that some linear inequalities clash: adding them with nonnegative weights gives 0 < 0 or similar.
floor
The largest integer not above a number. The floor of 2.7 is 2, and of −1.5 it is −2.
fragment
A restricted set of formulas the pipeline supports, named after an SMT-LIB logic.
kernel
The small core of Lean that checks every proof term. It is the part that must be trusted.
lemma
A proved helper statement used inside a larger proof.
linear term
A sum of variables times constants, plus a constant, such as 2x + 3y − 1.
proof core
One of Z3's two ways of recording a proof here: the legacy proof object or the clause log.
qf_lira
Quantifier-free linear arithmetic over Int and Real together.
refutation
A proof that a set of assertions leads to False.
rewrite
Replacing a term by an equal, simpler one, for example is_int (x + 1) by is_int x.
sort
The type of a value, such as Int, Real, or Bool.
tactic
A Lean command that builds part of a proof automatically, such as omega or grind.
theory lemma
A clause that holds by arithmetic alone, which Z3 adds during solving.
uninterpreted function
A function symbol with no fixed meaning, only that equal inputs give equal outputs.
