In one paragraph

This PR changes how the reconstructor proves one kind of rewrite step. Z3's rewriter regroups a large assertion: it flattens nested conjunctions and disjunctions and drops every tautology. The certificate must show that the result is equivalent to the original. Lean proved this with a general tactic that tries case splits, and on large formulas it hit its heartbeat limit. The reconstructor now writes an explicit propositional proof first. Each theory atom is an opaque leaf, and each dropped tautology is proved once by excluded middle. Six QF_UF quasigroup benchmarks that Lean rejected now verify. The trust boundary is unchanged, and no new axiom is used.

Background

Before this PR, the pipeline already exported certificates for these benchmarks. They use only equalities over one uninterpreted function and one uninterpreted sort. Lean checked almost all of each file in seconds, and only the rewrite lemma timed out. So the gap was scale, not a missing theory. Rewrites over arithmetic atoms already avoided the general tactic above 16 atoms, but other theory atoms had no such path. The work serves milestone 3 of the plan, "Equality and linear arithmetic".

What changed

  • Reconstructor, rewrite lemmas. A rewrite over more than 16 theory atoms is first proved from the Boolean structure of its two sides, by _leaf_equivalence.
  • Reconstructor, fallback. The old tactic proof stays as a second alternative, so a rewrite without the new proof keeps its previous text.
  • Propositional prover. A disjunction holding a formula and its negation is now a fact proved once by excluded middle, not a case split.
  • Tests. A generator builds inputs of this shape at any size, and Lean checks the new proof with the fallback removed.
  • Test data and docs. Two real quasigroup benchmarks became test inputs, and the plan and README record the measurements and open cases.

An analogy: a checklist asks "Is the door open or not open?". The old prover examined both possibilities for every such question, so each one doubled the work. The new prover ticks the question off once.

Review

The reviewer approved the change, with no blocker and no major finding. One minor finding and two nits were fixed in the second commit.

  • Minor, fixed. The reviewer saw that the tautology facts also reach rewrites over arithmetic atoms, and no test checked that in Lean. Hand-built QF_LRA variants did verify. But a later mistake there would silently fall back to the tactic that times out. A new QF_LRA test now removes the fallback, so Lean must accept the new proof.
  • Nit, fixed. The prover computed the facts even for a refutation, which never uses them. One benchmark got 336 unused proofs that way. The facts are now computed on first use.
  • Nit, fixed. Two tests located the rewrite by counting definitions and matching exact tactic text. An unrelated change could break them, so they now select the rewrites that carry a structural proof.
  • Suggestion, recorded. The reviewer found a failing input that the implementer believed did not exist. In a QF_UFLIA variant, Z3 reorients the equalities, so the two sides share no leaf. Lean rejects that input exactly as before the change, and the plan now lists it as open.

Risks and open questions

  • The prover change reaches every classical equivalence proof, so proofs of arithmetic rewrites can differ. No sample file outside the quasigroup family changed.
  • The fallback catches a proof that Lean rejects, but not one that runs out of heartbeats.
  • The threshold counts atoms, not difficulty, so three files that already verified grew slightly.
  • The CI result and the local gate result are not known yet.

What comes next

  • Support regroupings that also reorient equalities, starting from the reviewer's input.
  • Cut memory use for the other gensys files, whose Lean text is 31 to 195 MB.
  • Speed up the replay of a QF_IDL benchmark. A measured patch exists but is not in this PR.
  • Investigate the 21 sample files that Z3 does not answer within the scan's time limit.

Glossary

assertion
A formula the input states to be true, written (assert ...) in SMT-LIB.
axiom
A statement accepted without proof. Lean reports which axioms a finished proof depends on.
Boolean
The sort with the two values true and false. The Boolean structure of a formula is how it is built with and, or, and not.
case split
A proof step that handles each possibility separately, for example first "A is true" and then "A is false".
certificate
A file of evidence for a solver's answer that a separate program can check.
clause
A disjunction of literals, such as (or (not A) B).
conjunction
An "and" of formulas. It is true when every part is true.
disjunction
An "or" of formulas. It is true when at least one part is true.
equality
An atom (= s t) saying that two terms denote the same value.
equivalence
Two formulas are equivalent when each one implies the other. Lean writes this as Iff.
excluded middle
The law that A or not A holds for every statement A. In Lean it is Classical.em.
fuzzing
Testing a program on many randomly generated inputs.
heartbeat
Lean's unit for counting work. A proof that needs more heartbeats than its limit is rejected with a timeout.
interpretation
A choice of meaning for every uninterpreted sort and function. A refutation must hold for all of them.
lemma
A small proved statement used as one step of a larger proof.
literal
An atom or the negation of an atom, such as A or (not A).
opaque leaf
A sub-formula that a proof treats as one indivisible unit, without looking inside it.
propositional proof
A proof that uses only the meaning of and, or, not, and implication, never the meaning of the atoms.
QF_LRA
The SMT-LIB logic of quantifier-free linear arithmetic over the real numbers. QF_LIA is the same over the integers.
QF_UF
The SMT-LIB logic of quantifier-free formulas over equality and uninterpreted functions.
quasigroup
A set with one binary operation whose table has every element once in each row and column. The benchmarks ask about such tables.
reconstructor
The program that turns a certificate into Lean proof text.
refutation
A proof that a set of formulas implies false, so they cannot all hold together.
rewrite
A step that replaces a formula by an equivalent one, usually simpler. Example: dropping (or (not A) A) from a conjunction.
sort
The type of a value, such as Int, Real, or Bool.
tactic
A Lean command that builds part of a proof, sometimes by automated search. Example: grind.
tautology
A formula that is true whatever its atoms are, such as (or (not A) A).
theory atom
A smallest formula whose truth depends on a theory, such as the equality (= (op e0 e1) e2) or the comparison (<= x 3).
trust boundary
The set of things one must believe without checking them.
uninterpreted function
A function symbol with no fixed meaning. All that is known is that equal arguments give equal results.
uninterpreted sort
A sort declared by name only, with no fixed set of elements. Example: (declare-sort U 0).
