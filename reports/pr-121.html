Replay set operators as logged; reject default-map axiom only if used

Pull request #121 in levnach/z3, targeting master · OPEN · 2026-11-11T20:02:08Z · loop iteration 120

This pull request is open. It is not merged. The change commit is bcf078679.

In one paragraph

The replay of Z3's clause log now reads the four set operators when the log prints them by name. It also stops rejecting an input just because the log mentions the default-map axiom. That axiom cannot be proved in Lean, so a refutation that uses it is still rejected. A refutation that never uses it now gets a certificate with the axiom left out. On a sweep of random set inputs, more pass the Lean check and none is lost. Only Python code changed. No Lean theorem, axiom, or trust option changed.

Background

Before this PR the pipeline already certified many inputs over sets, which are arrays into the Boolean sort. It expected the log to show each set operator as a map, the form Z3's rewriter produces. When one assertion simplifies to false, Z3 logs the others as written, and the replay rejected those names. It also rejected any log that stated the default-map axiom, even when the refutation was two reads that never touched it. The work serves milestone 4 of the plan, "Broader theories and integration", which includes arrays.

What changed

  • Replay, set operators. You can now certify inputs whose log prints union, intersection, setminus, or complement by name instead of as a map.
  • Replay, default-map axiom. An input is now rejected for this axiom only when the refutation actually reaches it, and an unused one is dropped from the certificate.
  • Replay, a narrower shape test. The default value of a store over a map is no longer mistaken for the axiom, because that fact holds for every array.
  • Reconstructor. A certificate that states the default-map axiom as a theory lemma is now refused with a clear message, where before only Lean would fail.
  • After review. An input may declare its own uninterpreted function named union next to the set operator, and it still certifies.

An analogy for the second bullet. The solver keeps a notebook and writes one standard remark for every map it meets. The old replay threw the notebook away on seeing a remark it could not check. The new replay first asks whether the final argument cites it.

Review

Verdict: APPROVE. No blocker and no major finding.

  • Minor, recorded and not changed. The reviewer ran the sweep and saw three inputs change how they fail. Before, they were refused at export with a named reason. Now Lean fails later in a rewrite step, which is slower and less clear. The integrator checked one, seed 345, and found its old refusal was for the wrong reason. The real gap is rewrite steps with no Lean theorem yet. Nothing unsound happens, because Lean rejects.
  • Nit, fixed. The reviewer wrote an input that declares its own function named union beside the set union. It was refused with a misleading message. Z3 prints its own union with a sort annotation, so the replay now tells the two apart, and the input passes Lean. Testing this exposed a raw Python error for a function named intersection, now a proper export rejection.
  • Nit, fixed. No test covered the new rejection on a trimmed log, so a bug there could go unseen. The test now covers both kinds of log.
  • Nit, fixed. One ambiguous README sentence was reworded.

Risks and open questions

  • Later failures. Three sweep inputs now fail in Lean instead of at export, so tools that count Lean failures report them differently.
  • Platform. The pinned seeds and the trimmed-log test were chosen on a macOS build. A different log on Linux would first show as a failure of those tests.
  • Soundness. The PR argues nothing unchecked is admitted. The axiom is either unused and absent, or used and rejected.
  • Unknown. The local gate and CI results.

Glossary

array
A value that maps every index to an element, like a total lookup table. (Array Int Bool) maps integers to Booleans.
assertion
A formula the input states must hold, written (assert ...) in SMT-LIB.
axiom
A fact a solver uses without deriving it from other facts. A checker must prove it or refuse it.
Boolean
The sort with the two values true and false.
certificate
A file that records the steps of a refutation so that another program can check them.
clause
A disjunction of atomic formulas and their negations, such as "p or not q".
clause log
The list of clauses the solver writes while it works: assumed, derived, or stated by a theory.
constant array
An array with the same element at every index. The empty set is the constant array of false.
default value
The element an array takes at all but finitely many indices, when such an element exists. Written (default a).
default-map axiom
The array solver's claim that the default value of a map is the function applied to the default values of its arguments. It holds only when every argument has a default value, so Lean cannot prove it in general.
map
An array built by applying a function index by index, written ((_ map f) a b). Union is the map of "or".
refutation
A derivation of false from the assertions. It shows the assertions cannot all hold.
replay
Re-deriving each logged clause step by step to build a proof that can be exported.
rewriter
The part of a solver that simplifies terms before solving, for example turning (setminus a b) into a map.
select (read)
Reading an array at an index, written (select a i). For a set it asks whether i is a member.
set
In Z3, an array with Boolean elements. An index is a member when its element is true.
set operator
One of union, intersection, setminus (difference), and complement.
sort
The type of a value, such as Int, Real, Bool, or (Array Int Bool).
store
An array equal to another except at one index, written (store a i v).
theory lemma
A clause that is true by the rules of a theory alone, such as arrays or arithmetic, whatever the input says.
trimming
Removing from a log the clauses the refutation does not use. Here it is applied only to logs of 4 KB or more.
uninterpreted function
A function symbol the input declares without defining it. Only its name and sorts are known.
