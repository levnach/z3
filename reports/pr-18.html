In one paragraph

Before this PR, every Boolean rewrite step in a legacy proof object was checked in Lean by a truth table. That check tried every assignment of the atoms, so its cost doubled with each atom. This PR replaces it with a direct proof term. The term follows truth values through the connectives on both sides of the equivalence, and uses a case split only where that is not enough. The truth table remains as a fallback when the term builder gives up, so a false rewrite is still rejected. A refutation whose rewrites span a dozen or more atoms is now certified in under a second, and every emitted term stays axiom-free.

Background

The pipeline already certified propositional, uninterpreted-function, and linear-arithmetic refutations from two sources of evidence, the legacy proof object and the clause log. The scaling survey of 2026-09-25 named truth-table rewrites as one of two remaining resource cliffs: eight atoms took seconds, and twelve exceeded Lean's heartbeat limit. Iteration 17 hit that cliff on z3test 3632.smt2, whose legacy proof performs flattening of conjunctions and expands a Boolean distinct over 13 to 14 atoms, so it could be certified only through the clause log. This PR serves milestone 2 of the plan, the kernel-checked Boolean slice, by closing that gap.

What changed

  • Reconstructor, the prover. A Boolean rewrite step is now proved by a direct term that pushes truth values from one side of the equivalence to the other, one typed step at a time. Think of checking a circuit by following its wiring, instead of flipping every combination of switches.
  • Reconstructor, case splits. Where propagation stalls, the term splits on the most frequent atom using the excluded middle, and each branch ends in the goal or a contradiction.
  • Reconstructor, the fallback. A false equivalence, or one beyond the budget of 20,000 steps or 1 MB of text, still gets the old truth table, so bad rewrites are rejected exactly as before.
  • Reconstructor, witnesses. A rewrite lemma now takes only the decidability witnesses its term uses, often none.
  • Tests. Unit tests pin the witness sets, the fallback, and the expansion of xor, if-then-else terms, and distinct. Lean-backed tests now certify 3632 through the legacy proof object and wide rewrites over 8 to 24 atoms.
  • Documentation. Both READMEs and the plan carry a dated note.

Worked example

The input asserts a nested conjunction of twelve atoms and the negation of the last one. Z3's simplifier flattens the nesting one level at a time, so the proof contains ten rewrite steps, the widest over all twelve atoms. Both runs were made on the loop machine, with the merged code and with the scripts of the parent commit.

(a) The input

(declare-const a Bool) (declare-const b Bool) (declare-const c Bool) (declare-const d Bool)
(declare-const e Bool) (declare-const f Bool) (declare-const g Bool) (declare-const h Bool)
(declare-const i Bool) (declare-const j Bool) (declare-const k Bool) (declare-const l Bool)
(assert (and a (and b (and c (and d (and e (and f (and g (and h (and i (and j (and k l))))))))))))
(assert (not l))
(check-sat)

(b) Before: rejected

The exporter produced the same certificate before and after the PR. The old reconstructor wrote a truth-table lemma for each rewrite, with one cases block per atom.

(c) After: accepted

The new reconstructor generated these declarations for the widest rewrite. Cut lines are marked "..." and the one-line term is re-wrapped.

def formula_22 (_atoms : Nat -> Prop) : Prop := (And (formula_0 _atoms) (formula_21 _atoms))
def formula_92 (_atoms : Nat -> Prop) : Prop := (And (formula_0 _atoms) (formula_87 _atoms))
def formula_95 (_atoms : Nat -> Prop) : Prop := (And (formula_0 _atoms) (And (formula_1 _atoms) ... (formula_11 _atoms)...))
def formula_96 (_atoms : Nat -> Prop) : Prop := (Iff (formula_92 _atoms) (formula_95 _atoms))

The left side still nests one level, and the right side is the fully flattened conjunction.

private theorem rewrite_97 (_atoms : Nat -> Prop)
    : (formula_96 _atoms) := by
  unfold formula_96 formula_95 formula_92 formula_87 formula_11 ... formula_0
  exact (Iff.intro
    (fun (_f1 : (And (_atoms 0) (And (_atoms 1) ... (_atoms 11)))) =>
      ((have _f2 : (_atoms 0) := (And.left _f1);
        have _f3 : (And (_atoms 1) ... (_atoms 11)) := (And.right _f1);
        have _f4 : (_atoms 1) := (And.left _f3);
        have _f5 : (_atoms 2) := (And.left (And.right _f3));
        ...
        have _f14 : (_atoms 11) := (And.right (And.right ... _f3));
        have _f15 : (And (_atoms 0) (And (_atoms 1) ... (_atoms 11))) :=
          (And.intro _f2 (And.intro _f4 (And.intro _f5 ... _f14)));
        _f15) : ...))
    (fun (_f16 : ...) => ...))

Each have pulls one atom out of the assumed side, and the last one reassembles the other side. No case split and no witness is needed.

theorem unsat (_atoms : Nat -> Prop)
    (_h0 : (formula_22 _atoms))
    (_h1 : (formula_23 _atoms))
    : False :=
  let _step_24 : (formula_22 _atoms) := _h0
  let _step_27 : (formula_26 _atoms) := (@rewrite_27 _atoms)
  let _step_30 : (formula_29 _atoms) := (and_congr (Iff.refl (formula_8 _atoms)) _step_27)
  ...
  let _step_97 : (formula_96 _atoms) := (@rewrite_97 _atoms)
  let _step_99 : (formula_98 _atoms) := (Iff.trans _step_94 _step_97)
  let _step_100 : (formula_95 _atoms) := (Iff.mp _step_99 _step_24)
  let _step_101 : (formula_11 _atoms) := (And.right (And.right ... _step_100))
  let _step_102 : (formula_23 _atoms) := _h1
  let _step_104 : (formula_103 _atoms) := (False.elim (_step_102 _step_101))
  _step_104

The main theorem chains the lemmas with congruence and transitivity steps, extracts the last atom, and meets its negation. Before the PR it began with twelve witness wrappers.

Review

The reviewer approved the change with no blockers and no majors. One minor finding and three nits were raised.

  • Minor: the step budget did not bound term size. A parity rewrite over eight atoms stayed under the step limit but emitted an 11 MB lemma, which Lean rejected only after 140 seconds. The old truth table had failed in 8 seconds, so the slow path could eat a matrix cell's whole time limit. Fixed with a second budget of 1 MB on the generated text, so seven and eight atoms now fall back within seconds.
  • Nit: generated names detected by a regular expression. This would break if another helper produced a similar name. Fixed by keeping the set of generated names.
  • Nit: an unused witness was recorded. Rewriting (and p (not (not p))) to p discarded a double-negation step but still demanded its witness. Fixed so a witness is recorded only when its step is kept, with a unit test.
  • Nit: shared subformulas were read repeatedly. Partly fixed with a memo that reads each node once. Keying the prover's state by node id remains a follow-up.

After the fixes the reviewer's fuzzer still produced 400 of 400 direct, axiom-free terms.

Risks and open questions

  • Nothing new is trusted. Lean checks the direct term as strictly as it checked the truth table. A wrong term is rejected, and a false equivalence falls back to a truth table that Lean rejects as before.
  • Lemma signatures changed. Nothing downstream depends on the witness set.
  • Text size is quadratic. Each step restates its full proposition, so the 24-atom test lemma is about 630 KB, and the 1 MB budget may make some valid wide rewrites fall back.
  • Parity is still hard. Xor chains fall back at seven atoms, where the old truth table already failed.
  • Unknown. The result of the GitHub CI run on master after the merge is not recorded in this iteration's inputs.

What comes next

  • Name shared subformulas in the generated steps and key the prover's state by node id, so wide lemmas become linear in size.
  • Let the new prover also handle wide arithmetic rewrites, which still use an older helper with a tactic fallback.
  • Adopt a trimmed version of the reviewer's fuzzer as a regular Lean-backed test.
  • Return to the remaining iteration-17 candidates, starting with define-sort.

Glossary

atom
A Boolean variable or a predicate with no Boolean connectives inside it. In the example, a to l are atoms.
axiom-free
A Lean proof that relies on no axioms at all, which Lean reports through #print axioms.
Boolean
Having one of the two truth values, true or false. SMT-LIB writes the Boolean sort as Bool.
case split
Proving a goal twice, once assuming a statement is true and once assuming it is false.
clause
A disjunction of literals, where a literal is an atom or its negation. For example, (not a) or b.
clause log
Z3's record of the clauses it learned while solving, an alternative source of proof evidence to the legacy proof object.
congruence
Replacing equal parts inside a larger expression keeps the whole equal. If p is equivalent to q, then (a and p) is equivalent to (a and q).
conjunction
An "and" of several formulas, true only when all of them are true.
connective
An operator that combines formulas, such as and, or, not, implies, xor, or if-then-else.
decidability witness
A Lean value stating that a proposition is either known true or known false, so a proof may split on it. Written Decidable p.
distinct
The SMT-LIB predicate saying that all its arguments differ pairwise. Over Booleans, three or more arguments make it false.
equivalence
Two formulas that have the same truth value in every assignment. Written Iff in Lean.
excluded middle
The principle that a proposition is true or its negation is true. Here it is used only on atoms that have a decidability witness.
flattening
Rewriting a nested and (or a nested or) into one and (or or) with all the parts listed side by side.
fuzzing
Testing with many randomly generated inputs to find cases a hand-written test would miss.
heartbeat
Lean's unit of work. A proof that exceeds the heartbeat limit is rejected as a deterministic timeout.
if-then-else term
A term that picks one of two values based on a condition, written ite in SMT-LIB.
legacy proof object
Z3's older proof format, a tree of inference steps such as rewrite, monotonicity, and unit resolution, which the exporter saves as JSON.
lemma
A small theorem proved separately and then used inside a larger proof.
linear real arithmetic
Formulas over real numbers using addition, comparison, and multiplication by constants only. SMT-LIB calls the quantifier-free version QF_LRA.
parity
Whether an odd or even number of atoms are true. An xor chain computes parity, and no propagation shortcut settles it.
proof term
A proof written as an explicit expression that Lean's kernel checks directly, as opposed to a tactic script that searches for a proof.
propositional
Built only from Boolean atoms and connectives, with no arithmetic or functions.
refutation
A proof that a set of assertions leads to a contradiction, that is, that they cannot all be true.
rewrite step
A proof step in which Z3's simplifier replaces a formula by an equivalent one, such as flattening a nested and.
sort
The type of a value in SMT-LIB, such as Bool, Int, or Real.
tactic
A Lean command that builds a proof automatically, such as cases, decide, or grind.
truth table
A proof that checks a Boolean formula under every assignment of its atoms. With n atoms it has 2 to the power n rows.
uninterpreted function
A function symbol with no fixed meaning, about which only equality reasoning is allowed: equal inputs give equal outputs.
xor
Exclusive or, true when exactly one of its two arguments is true.
