Certify reads of arrays equated to constants and commuted array-ext

In one paragraph

This PR closes two gaps in the Lean reconstruction of proofs about constant arrays. First, a CNF lemma may read an array that an equality ties to a constant array. No fact gave the constant array's value at that index, so the tactic grind could not finish. The reconstructor now states that value, and grind links the two reads by congruence. Second, Z3's congruence closure treats the extensionality witness of two arrays as commutative. Lean had no matching fact, so each generated file now proves one as a theorem. Both additions are proved in the file, so the trusted base does not grow. Two Real-sorted refutations that Lean rejected now check.

Background

Before this PR, the pipeline already certified many constant-array problems, including long store chains compared with constant arrays. But its random test generator only built arrays with Int indices and Int elements. A new sweep over Real sorts found two seeds, 48 and 87, that Lean rejected. Each failure also has a small Int input, so neither is really about Real numbers. This work serves milestone 4 of the project plan, "Broader theories and integration". That milestone treats arrays as a separate extension to be completed end to end.

What changed

  • Reconstructor: a CNF lemma reading an array equated to a constant array now gets the constant array's value at each read index.
  • Reconstructor: each extensionality witness now has a proved fact that swapping its two arrays gives the same witness.
  • Test generator: random constant-array problems can now use Int or Real index and element sorts, with unchanged Int problems per seed.
  • Regression tests: three small inputs and the two failing Real seeds are now permanent tests, each checked for its expected fragment.
  • Documentation: the project plan and the examples README describe both new facts.

Two analogies help. If box a is a copy of a box holding 1 in every slot, you still must read slot k of the original to know slot k of the copy. The new facts do that reading, at most 64 per lemma. And just as the distance from A to B equals the distance from B to A, a spot where a and b differ is a spot where b and a differ.

This input is the PR's new test read_of_an_array_equated_to_a_constant. All outputs come from real runs for this report.

(a) The input

(set-logic ALL)
(declare-const a (Array Int Int))
(declare-const k Int)
(assert (= a ((as const (Array Int Int)) 1)))
(assert (distinct 3 (select a k) (select a 0)))
(check-sat)

Array a equals the constant array of 1s, yet the input demands three pairwise distinct values, which is impossible.

The main theorem says that the two assertions together imply False, for every interpretation.

private theorem th_lemma_15 (_atoms : Nat -> Prop) (_vars : Nat -> Int) (_m : Interpretation)
    : (formula_14 _atoms _vars _m) := by
  unfold formula_14 formula_13 formula_12 formula_11 term_6 term_5 term_4 formula_3
  have _t2 : (term_2 _atoms _vars _m) = (@_const_array Int Int (((1 : Int)))) := rfl
  ...
  have _dc2_5 := _select_const (I := Int) (((1 : Int))) (_vars 0)
  first | omega | grind (splits := 64)

This is the CNF lemma that failed before. The new line _dc2_5 states that slot k of the constant array holds 1, and now grind succeeds.

private theorem _array_diff_comm {I E : Type} (h : Nonempty I) (a b : I -> E) :
    _array_diff h a b = _array_diff h b a := by
  have _p : (fun _j => Not (a _j = b _j)) = (fun _j => Not (b _j = a _j)) :=
    funext (fun _j => propext (Iff.intro (fun _n _e => _n _e.symm) (fun _n _e => _n _e.symm)))
  exact congrArg (@Classical.epsilon I h) _p

This new theorem, the second fix, appears in every generated file. This input never uses it, but the test commuted_extensionality_witnesses does.

Review

The reviewer approved, with no blocker or major findings. They confirmed the new theorem is sound and adds no axiom.

  • Minor, fixed. The reviewer imagined someone auditing a generated file and finding the new facts unexplained. The README had not been updated. Commit 998120222 fixed it.
  • Nit, fixed. The pinned-seed test guessed the fragment by looking for the word "Real" in the input. A seed mixing Int and Real would fail for a reason unrelated to Lean. The test now derives the fragment from the chosen sorts.
  • Suggestion, not changed. One lemma could get up to 640 chain reads plus 64 new reads. That is still bounded, so it stays a follow-up.
  • Suggestion, kept. A test asserts exactly two witnesses, which could break if the certificate shape changes. It was kept because it shows both argument orders are exercised.

Risks and open questions

  • Lemmas over constant arrays carry more facts, capped at 64. Sweeps showed no slowdown.
  • CI and local gate results were not available for this page.

What comes next

  • Indices written as unsimplified numerals, such as (/ 2 2) next to 1.0, which grind keeps apart.
  • The "arithmetic step over both Int and Real atoms" rejection for Real-indexed arrays of Int elements.
  • Simpler CNF lemmas, by preferring the assertion a clause was split from.
  • One shared limit for the new reads and the chain reads.

Glossary

array
A total map from an index sort to an element sort. (Array Int Int) maps every integer to an integer.
clause
A disjunction of literals: at least one of them must be true.
CNF lemma
A clause, proved on its own, that links a learned clause to the original assertions. CNF stands for conjunctive normal form.
commutative
An operation is commutative if swapping its two arguments does not change the result, as with x + y = y + x.
congruence
The rule that equal inputs give equal outputs: if a = b, then f(a) = f(b).
congruence closure
The algorithm that groups terms into classes of equal terms, using equalities and congruence.
constant array
An array holding the same value at every index, written ((as const (Array Int Int)) 1) in SMT-LIB.
distinct
The SMT-LIB predicate saying its arguments are pairwise different.
equality
A formula (= s t) stating that two terms denote the same value. Between arrays, it means equal at every index.
extensionality witness
For two arrays, an index where they differ, if any exists. Z3 writes it (_ array-ext 0). Extensionality says arrays equal at every index are equal.
fragment
A restricted logic named by the theories it allows, such as qf_uflra: quantifier-free, uninterpreted functions, linear real arithmetic.
index
The position at which an array is read or written.
refutation
A proof that a set of assertions leads to a contradiction, that is, to False.
seed
A number that fixes a random generator's choices, so the same seed always gives the same test problem.
sort
The type of a value, such as Int, Real, Bool, or (Array Real Real).
store
The array update (store a i v): an array equal to a except that index i holds v. Reading uses select.
tactic
A Lean command that builds part of a proof automatically. grind is a tactic that combines congruence closure with arithmetic.
theorem
A statement together with a proof that Lean has checked.
trusted base
The parts of a check that are accepted without proof, such as axioms. Keeping it small makes the result more reliable.
