In one paragraph

Z3 easily refutes the negation of a distinct over many terms pinned to different numbers. Its refutation refutes every pair, but Lean rejected the certificate. This PR changes only the Lean reconstructor, in three ways. The rewrite of the negated distinct into a disjunction of pair equalities is now proved by one De Morgan step per pair, not by a tactic search that ran out of heartbeats. Lemma steps over a wide clause now reach each literal from a nearby let-bound tail, so their text grows linearly. And outlining now gives a very wide step a chunk of its own. A negated distinct of 40 terms now checks in Lean in about 8 seconds. The trust boundary is unchanged.

Background

The previous PR taught the pipeline to certify an asserted distinct of more than 32 terms. It left one case open, recorded in the plan as "still open": a negated wide distinct whose every pair the proof refutes. Such inputs exported a certificate, but the Lean text was quadratic in the number of pairs, and Lean ran out of heartbeats. This PR closes that case. It serves milestone 3 of the plan, equality and linear arithmetic, in the Boolean and equality proof infrastructure.

What changed

  • A rewrite from (not (distinct ...)) to the disjunction of its pairs now gets a short, step-by-step Lean proof, one line per pair.
  • A pair written the other way round, (= aj ai), is handled too, by also applying symmetry of equality.
  • Any rewrite of a different shape still goes to the old automated proof, so nothing that worked before is lost.
  • A lemma step that discharges hundreds of hypotheses now produces text of linear size, like a book with a bookmark every 32 pages instead of counting from page one each time.
  • A proof step with more than 64 premises or literals now counts as that many steps when outlining, so it is checked in a small chunk of its own.

Worked example

This input says eight Int constants are not all distinct, then pins each to a different number. It follows a helper from the PR's new tests. All output below comes from real runs.

(a) The input

(set-logic QF_LIA)
(declare-const x0 Int) (declare-const x1 Int) (declare-const x2 Int) (declare-const x3 Int)
(declare-const x4 Int) (declare-const x5 Int) (declare-const x6 Int) (declare-const x7 Int)
(assert (not (distinct x0 x1 x2 x3 x4 x5 x6 x7)))
(assert (= x0 0)) (assert (= x1 1)) (assert (= x2 2)) (assert (= x3 3))
(assert (= x4 4)) (assert (= x5 5)) (assert (= x6 6)) (assert (= x7 7))
(check-sat)

The current reconstructor wrote a 65 KB Lean file. check_lean.sh accepted it: "Lean checks passed."

...

The distinct becomes a conjunction of 28 disequalities, and the first assertion is its negation.

def formula_35 (_atoms : Nat -> Prop) (_vars : Nat -> Int) : Prop := ((term_0 _atoms _vars) = (term_1 _atoms _vars))
...
def formula_62 (_atoms : Nat -> Prop) (_vars : Nat -> Int) : Prop := (Or (formula_35 _atoms _vars) (Or (formula_36 _atoms _vars) ... (formula_61 _atoms _vars) ...))
def formula_63 (_atoms : Nat -> Prop) (_vars : Nat -> Int) : Prop := (Iff (formula_9 _atoms _vars) (formula_62 _atoms _vars))

Z3's rewrite says the negated distinct is equivalent to the disjunction of the 28 pair equalities.

private theorem rewrite_64 (_atoms : Nat -> Prop) (_vars : Nat -> Int)
    : (formula_63 _atoms _vars) := by
  unfold formula_63 formula_9 formula_8 formula_62
  refine Iff.trans Classical.not_and_iff_not_or_not (or_congr Classical.not_not ?_)
  refine Iff.trans Classical.not_and_iff_not_or_not (or_congr Classical.not_not ?_)
  ...
  exact Classical.not_not

Each line peels one pair: De Morgan turns "not (A and rest)" into "not A or not rest", then double negation turns "not not (x = y)" into "x = y". There are 27 such lines and one final exact.

theorem unsat (_atoms : Nat -> Prop) (_vars : Nat -> Int)

    ...
    (_h8 : (formula_25 _atoms _vars))
    : False :=
  ...

The final theorem takes exactly the nine original assertions and concludes False.

This small input shows only the new rewrite proof. The other two changes need wider steps, and the PR's 40-term test covers them.

Review

The reviewer approved, with no blocker and no major finding.

nitOutlining docstring out of datefixed

The untested branch. The reviewer looked for an input where Z3 writes a pair as (= aj ai), and found none. So a wrong symmetry step would pass every test, and a future rewriter change could break certification silently. The fix reverses two pair equalities in a real certificate, and a new Lean test checks the result. A tampered copy without the symmetry step is rejected.

Many tiny theorems. The 40-term input yields about 1,284 outlined theorems. Each single-use premise of a very wide unit resolution becomes its own theorem. This is correct and fast, so grouping them became a follow-up.

The stale docstring. The outlining comment still described cuts by step count only. It now mentions the width weighting.

Risks and open questions

  • Outline boundaries change only for proofs with a step wider than 64 and more than 500 steps. Those proofs now produce more, smaller theorems.
  • Lemma text changes only for clauses wider than 32 literals.
  • The new rewrite proof uses only standard classical lemmas, and Lean checks it.
  • The 33-term chain and the 34-term uninterpreted-sort input are too slow for CI, so they are not in it.

What comes next

  • Group the single-use premises of a very wide unit resolution into shared chunks.
  • A positive distinct rewritten into its conjunction of disequalities still goes to grind. No such input has been seen yet.
  • The other open items from iteration 90 remain, such as reordered distincts over the same terms.

Glossary

clause
A disjunction of literals, such as (or p (not q) (= x 1)).
conjunction
An "and" of formulas. It is true when every part is true.
De Morgan's law
The rule that "not (A and B)" is equivalent to "(not A) or (not B)".
disjunction
An "or" of formulas. It is true when at least one part is true.
distinct
The SMT-LIB operator that says all its arguments differ. (distinct a b c) means a ≠ b, a ≠ c, and b ≠ c.
double negation
The rule that "not not A" is equivalent to A. Lean's Classical.not_not states it.
heartbeat
Lean's unit of work. A proof that uses more than its heartbeat budget is stopped with a timeout error.
hypothesis
A formula assumed for a while inside a proof, then discharged by a lemma step.
lemma (proof rule)
The step that turns a contradiction found under some hypotheses into a clause saying at least one hypothesis is false.
let binding
A name given to a value once, so later code can reuse it instead of repeating it.
literal
An atomic formula or its negation, such as p or (not (= x y)).
outlining
Splitting a long proof into separately checked theorems, so each stays within Lean's heartbeat budget.
refutation
A proof that a set of assertions leads to False.
rewrite
A proof step saying one formula is equivalent to a simpler one, as produced by Z3's simplifier.
sort
The type of a value, such as Int, Real, Bool, or an uninterpreted sort U.
tactic
A Lean command that builds part of a proof. Some tactics search for a proof automatically, such as grind.
trust boundary
The set of things one must trust for a checked proof to be believed, here Lean's kernel and its standard axioms.
unit resolution
The step that removes literals from a clause using facts that refute them, leaving a shorter clause.
