In one paragraph

This PR makes the exporter's sweep of a cnf lemma succeed on two shapes of formula where it used to give up. First, the sweep now reads through a chain of nested conjunctions instead of writing one link per level. Second, when its refutation of the clause gets stuck, it tries again deeper, closer to the atoms. Two integer difference logic benchmark files, qlock-4-10-8 and qlock-4-10-9, now verify in Lean. Before, each failed because a fallback tactic ran out of heartbeats. Only the Python exporter changed, so the trusted base is the same.

Background

Before this PR, both qlock files exported to Lean text, but the check failed after about 70 seconds. In each file, a cnf lemma had no structural proof, only a fallback that unfolds over a thousand definitions. Two things stopped the sweep. A deeply nested conjunction cost a quadratic amount of proof text. And Z3 had logged the clause over a formula simplified under unit clauses. The clause and the assertion then had no matching gate above the atoms. The files are integer difference logic, which belongs to milestone 3, equality and linear arithmetic.

What changed

Exporter

  • A conjunction nested n levels deep now costs the sweep one link instead of n links, so its proof text grows linearly.
  • A refutation that ends without a contradiction is now repeated one round further down the formula, up to eight rounds where there were three.

An analogy for the first change: read ((a and b) and c) and d as the flat list a, b, c, d, without justifying every bracket.

Tests and documentation

  • New tests pin both mechanisms on small generated formulas, and a slow test checks the whole qlock-4-10-8 file in Lean.
  • The plan and the README describe the new sweep and correct an older misdiagnosis of the failing lemma.

Worked example

The newly certified files are over 100 kB each. The PR's tests use a small stand-in from the generator nested_under_units, shown here at two levels.

(a) The input

(set-logic QF_LIA)
(declare-const i Int) (declare-const j Int) (declare-const u Bool)
(declare-const p0 Bool) (declare-const r0 Bool)
(declare-const p1 Bool) (declare-const r1 Bool)

(assert (not r0))
(assert (not r1))
(assert (or (and (or (and (or (<= i j) (not u)) p0) r0) p1) r1))

A caveat: on an input this small the ordinary proof searches succeed. Run plainly, the old and new pipelines write the same Lean file, which Lean accepts. The runs below make the searches give up, as the PR's test does.

Review

Verdict: approve, with no blocker and no major finding.

  • Minor, fixed. The reviewer swept a clause that does not hold, so no proof exists. The new retry loop ran eight searches, most of them identical, and a large case slowed from 0.26 s to 15.5 s. A file with many such lemmas would pay that each time. The sweep now skips a search over input it has already read, and the large case takes 3.3 s.
  • Nit, fixed. A test checked the link count with "at least". For one case that meant "at least zero", which can never fail. It now checks exact counts.
  • Nit, fixed. A table row in the plan still called the failing lemma an arithmetic one.
  • Nit, corrected. Two numbers in the implementer's summary did not match the scan they cited. The PR description uses the scan's numbers.

Risks and open questions

  • Four sample texts change. All were checked in Lean before and after, and inputs outside the sample will change the same way.
  • A failing sweep still runs more searches than before, each bounded by step and text limits.
  • A link through a very long chain can exceed a link's limits. It is then dropped, and the refutation reads the chain itself.
  • Only the slow test tier guards qlock-4-10-8, and qlock-4-10-9 is not in the repository.

What comes next

  • A chain above about 630 levels is still not swept, because inner gates still count against a size limit. This is the first follow-up.
  • An equivalence or implication that stands for its class is never read through.
  • Nine cnf lemmas in the sample still have no structural proof.
  • The batch carrying this change is verified on a second machine before it goes upstream, where CI runs.

Glossary

assertion
A formula the input states as true, written (assert ...) in SMT-LIB.
atom
A formula with no Boolean connective inside, such as p or (<= i j).
Boolean
Having one of the two values true and false. Boolean reasoning uses only connectives such as and, or, and not.
canonical gate
One agreed way to write a gate, with its operands flattened and in a fixed order, so that two differently grouped gates can be compared.
chain of modules
A large Lean text split into files of about 1 MB that Lean checks one after another.
clause
A disjunction of literals, such as (or p (not q)).
cnf lemma
A proof step saying that a clause Z3 logged follows from the asserted formulas by Boolean reasoning. CNF stands for conjunctive normal form, a conjunction of clauses.
conjunction
An "and" of formulas. It is true when all its operands are true.
differential fuzzing
Testing two versions of a program on many random inputs and comparing their results.
disjunction
An "or" of formulas. It is true when at least one operand is true.
equivalence
A statement that two formulas always have the same truth value, written Iff in Lean.
equivalence class
A set of formulas known to be equivalent to each other. The sweep groups gates into such classes to decide what to link.
gate
One connective applied to its operands, such as a single and or or node inside a larger formula.
heartbeat
Lean's unit of work. A proof that uses more heartbeats than its limit is stopped with a timeout.
implication
A formula "if A then B". It is false only when A is true and B is false.
integer difference logic
The fragment of arithmetic whose atoms compare the difference of two integers with a constant, such as x - y <= 3. Its SMT-LIB name is QF_IDL.
linear arithmetic
Arithmetic where variables are only added and multiplied by constants, never by each other.
link
In a sweep, a small theorem stating that a gate is equivalent to its canonical gate.
literal
An atom or the negation of an atom.
proof search
An automatic attempt to find a proof, here by the exporter, within limits on steps and text. It can give up.
quadratic
Growing with the square of the input size: twice the depth costs four times the text.
refutation
A proof that a set of formulas cannot all be true, ending in False.
structural proof
A proof that follows the shape of the formula gate by gate, instead of handing the whole formula to a general tactic.
sweep
The exporter's structural proof of a cnf lemma: it links matching gates of the two formulas one by one, then refutes the negated clause through the links.
tactic
A Lean command that builds part of a proof, such as omega for linear integer arithmetic.
trusted base
The parts that must be correct for a verified result to be believed. The exporter is outside it: Lean checks whatever the exporter writes.
unfold
To replace a defined name by its definition inside a proof.
unit clause
A clause with one literal, such as u or (not r0). It fixes the truth value of its atom.
